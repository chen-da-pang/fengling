# Issue tracker: GitHub

Issues for this repository live in `chen-da-pang/fengling` on GitHub.
Use `gh issue view <number> --comments` to read an issue and its comments.
Use `gh issue list` to find issues; check their labels and state.
Use a temporary body file with `gh issue create --body-file` or
`gh issue comment --body-file` for multiline text.
Use `gh issue edit` to update labels. Follow `CONTRIBUTING.md` for the
issue, branch, validation, pull request, and review workflow.

PRs as a request surface: no.
